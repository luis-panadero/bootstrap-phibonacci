# Bootstrap 3, Maintained by Phibonacci Creativo

**Bootstrap 3, Maintained by Phibonacci Creativo** is a drop-in replacement for [Bootstrap 3.4](https://getbootstrap.com/docs/3.4/) with security patches and ongoing maintenance by [Phibonacci Creativo](https://www.phibonacci-creativo.com/). It is intended for projects that rely on Bootstrap 3 and require continued support and security updates.

## Installation

You can install Bootstrap Phibonacci by cloning the repository:

```sh
git clone https://github.com/phibonaccicreativo/bootstrap-phibonacci.git
```

---

## Usage

Include the CSS and JS files from the `dist` directory in your project, just as you would with Bootstrap 3:

```html
<link rel="stylesheet" href="dist/css/bootstrap.min.css">
<script src="dist/js/bootstrap.min.js"></script>
```

You can also use the LESS source files for custom builds.
